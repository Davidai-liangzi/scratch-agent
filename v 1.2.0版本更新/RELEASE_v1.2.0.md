# v1.2.0 —— 交互体验打磨 + 首次交付质量兜底

> 这一版做两件事：把「用起来」的粗糙处磨平，把「生成出来」的成品质量兜住。
> 所有改动都来自实际使用中踩到的坑，不是拍脑袋加功能。

---

## ✨ 新增功能

### 1. API 额度面板
右侧独立面板，仿 OpenAI 控制台的 Usage / Billing 样式：

- **余额**：能查到余额的厂商直接显示剩余额度（大号数字 + 已用/总额进度条 + 币种 + 更新时间）
- **用量**：全厂商通用的本地估算 —— 累计 token 与估算花费（元），支持 7 天 / 30 天 / 全部切换
- **降级**：厂商不提供余额接口、或 Key 无权限时，明确说明原因，只展示本地估算，不报错
- **中转站**：支持「自定义 / OpenAI 兼容」厂商，可填 `base_url` 与模型名

### 2. 问题反馈
设置里新增入口，写一段话就能一键送达开发者：

- 自动附带版本、系统信息与**脱敏**日志，方便定位问题
- **API Key 任何情况下都不离开客户端**
- 发不出去（没配地址 / 网络不通 / 被拒收）时自动落成 `feedback/*.txt`，内容不丢

### 3. 编辑器安装引导
以前没装编辑器时，只会在日志里丢一句「打开失败」。现在：

- **弹窗让你选**：装一个新的，或用已经有的打开
- 候选覆盖 TurboWarp、Scratch 桌面版、Bilup 等社区改版，以及微软商店 / 官网 / GitHub 多种渠道
- 国内优先走 CDN（实测 GitHub 资产在国内被限速到 ~51 KB/s，差的不是你的带宽）
- 顺带修掉一个真 bug：**商店版 TurboWarp / Scratch 以前完全检测不到**（旧代码只查 3 个固定路径，商店版装在 `WindowsApps` 下）

### 4. 拖拽添加 / 替换素材
替换素材面板不再只能点按钮：

- 拖到**表格某一行** → 替换该行素材
- 拖到**候选图片条 / 面板空白处** → 自动加入候选
- 拖到**「＋ 新增素材」区域** → 自动新增角色 / 背景（名称取文件名，类型按宽高比自动判定）
- 新增**重命名**：角色名 / 背景名 / 造型名三层，点「应用」后同步写回原项目

### 5. 打字机输出与等待动画
- AI 回复**逐字上屏**，不再一大坨整块蹦出；带闪烁光标
- 等待模型时底部显示**三个上下跳动的圆点**，首字到达即消失

## 🎨 交互改进

- **不再被强制拽到底**：生成期间可以用滚轮上滑查看历史，右下角新增「↓ 回到底部」
- **生成完自动进气泡**：取消「点箭头结束本轮」；`.sb3` 以卡片形式出现在 AI 气泡里，**点卡片直接打开**
- **替换素材按钮提前出现**：读完 / 生成完 `.sb3` 就能点，不必先结束本轮
- 替换面板支持**增删**素材（候选条与工程素材本身同步）

## 🛡 生成质量：从「嘱咐模型」转向「程序验收」

这是本版最花功夫的部分。核心判断：**继续往提示词里堆规则走不通** —— 有实证上限（模型 token 级 F1 与解析成功率都 > 0.93，但语义完全对齐的样本不到 18.9%）。所以改成让程序自己验收：

**① 设计阶段先把关键决策定死**
复杂需求先生成「设计大纲」，并且现在必须写清三件事：

- **玩家怎么移动**（哪些键、哪个轴）
- **可收集物从哪出现** —— 必须落在玩家够得到的范围内
- **每一站用哪张背景** —— 必须与该站讲解内容相关

配套内置了「商店 / 餐厅 / 商场中庭」等通用场景背景，素材库缺题材时不再拿「派对」「冰箱」凑数。

**② 静态契约检查（7 条）**
帽子积木唯一、广播有发有收、非法自增写法、素材声明完整、占位符残留、角色造型声明、大纲逐站背景 —— 全部是**零误报的确定性判定**。

**③ 运行时判据（6 条），并且会点会按键**
无头运行不再只是「绿旗跑 5 秒看看」：

- 会依次点击每个可见角色、按下方向键与空格
- 如果代码里写了 `when clicked` / `when key`，但点完按完**画面、变量、台词全都没变** → 判定交互没接上
- 另外检查：编译/运行时错误、绿旗脚本没生效、画面全空、克隆体泄漏

**④ 自动补造型声明**
素材画好却忘写声明时（角色会完全隐形、也点不到，而语法检查不报错），程序按 `assets/` 里的真实文件自动补上，不再浪费一轮修复。

**⑤ 回炉更省**
修复轮只发送与报错相关的文件；提示词补上两个真实踩过的语法坑（`change_x` 只吃数字字面量、运动积木必须带 `motion.` 前缀），并要求「一次把所有问题改完」。

### 实测效果（6 条需求用例）

| 指标 | 改进前 | v1.2.0 |
|---|---|---|
| 打包成功 | 6/6 | **6/6** |
| 交付即无问题 | 6/6（但其中 2 条是空白背景，检查器看不见） | **6/6** |
| 总 token | 161,678 | **143,293（−11%）** |
| 总用时 | 611s | **386s（−37%）** |

检出能力从「2 条运行时判据」扩到「7 条静态 + 6 条运行时 + 交互冒烟」，**成本反而更低**。

## 🐛 修复的问题

- **官方素材名含空格时静默失效**：`@official:Blue Sky`、`@official:Room 1` 这类名字解析不出来，导致舞台/角色空白，且不报错
- **角色缺造型声明直接隐形**：素材文件画了但没挂上，打包、运行时都不报错
- **收集物永远够不到**：飞船只能左右移动，星星却撒在上方
- **背景与讲解内容不匹配**：彩妆区配派对场景、美食区配冰箱内部
- **商店版编辑器检测不到**：明明装了，程序却当没装

## 📦 下载与安装

便携版，解压即用，无需安装 Python / Node：

1. 下载 `ScratchGenerator_v1.2.0.zip` 并解压
2. 双击 `ScratchGenerator.exe`
3. 首次运行按提示填写 API Key（保存在 exe 同目录的 `config.json`，不会上传）

> 注意：本版重新打包后**不包含旧版配置**，首次运行需要重新填一次 API Key。

## 已知边界

- 自动交互冒烟只验证「有没有反应」，不验证「反应对不对」—— 具体玩法仍需人工试玩确认
- 余额查询依赖各厂商接口；不支持或 Key 无权限时会明确降级为本地估算
