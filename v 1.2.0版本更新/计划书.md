# v1.1.2 版本更新计划书

> 本次更新聚焦「AI 对话框观感优化」，共两项功能。

## 一、更新目标

1. AI 回复逐字输出（打字机式），不再「一段段」整块蹦出。
2. 跳舞的省略号加载动画：等待 AI 回复时在对话框底部闪烁。

## 二、功能一：AI 回复逐字输出（打字机）—— ✅ 已完成

### 现状与根因

流式链路本身已具备：

| 层 | 文件 | 现状 |
|---|---|---|
| 请求层 | `core/llm.py` | SSE 流式读取，每个增量片段回调一次 `on_chunk` |
| 桥接层 | `gui.py` | 后台线程累积 chunk，约每 50ms 合并一次经 `_ui_queue` 推送 |
| 展示层 | `ui/webview.html` | `appendChunk` 直接 `textContent +=`，`endStream` 一次性转 markdown |

根因：前端「网络来多少就立刻上屏多少」，模型输出不均匀时一大坨字符同时出现 → 观感「一段段」。

### 方案（纯前端，`ui/webview.html`）

- `appendChunk` 只进缓冲 `pendingText`，定时器 `typeStep` 按自适应速率逐字上屏。
- `endStream` 标记流结束，缓冲打完才 `finalizeStream` 转 markdown + 高亮 + 复制按钮。
- 新增 `.stream-bubble::after` 闪烁光标。

### 改动位置

- `ui/webview.html`：流式区重构（`pendingText` / `typingTimer` / `typeStep` / `finalizeStream`）+ 光标样式 + `clearMessages` 兜底。

## 三、功能二：跳舞的省略号加载动画（本次实施）

### 目标

等待 AI 回复（模型「思考 / 生成」阶段，即首字到达之前）时，在对话框底部显示三个上下跳动的圆点；首字到达后自动消失。

### 设计（纯前端，`ui/webview.html`）

- **CSS**：`.typing-dots` 容器（AI 气泡样式）+ 三个 `.dot` 圆点，`@keyframes dot-bounce` 上下跳动，动画延迟依次错开（0 / 0.2s / 0.4s）。
- **JS**：`showTyping()` 创建并显示圆点；`hideTyping()` 移除。
- **接线**：
  - 显示：`appendStep` 收到 `outline` / `request` 步骤的 `start` 事件时（即等待模型生成文字时）。
  - 隐藏：`appendChunk` 收到首个 token；`endStream` 收尾；`clearMessages` 清空会话。

### 实现步骤

- [x] 步骤 1：新增 `.typing-dots` 样式 + `dot-bounce` 动画。
- [x] 步骤 2：新增 `showTyping` / `hideTyping` 函数。
- [x] 步骤 3：接线 `appendStep` / `appendChunk` / `endStream` / `clearMessages`。
- [x] 步骤 4：自检。

## 四、验收标准

1. 生成开始时底部出现三个上下跳动的圆点，首字到达后消失。
2. 逐字输出正常（回归验证功能一）。
3. 停止生成、切换会话后无残留、无报错。

## 五、假设与说明

- 省略号仅在 `outline` / `request`（等待模型生成文字）阶段显示；`assets` / `pack` / `verify` 属本地处理，已有步骤卡片转圈提示，不再显示省略号。
- 纯前端改动，后端 `core/llm.py`、`gui.py` 不动。
