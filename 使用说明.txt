Scratch 项目生成器 · 使用说明
================================

一、这是什么
    用一句话描述你想做的游戏，程序会调用 AI 生成 Scratch 项目（.sb3），
    并可直接用 TurboWarp 打开预览。支持在已有项目上继续修改。

二、运行环境
    Windows 10/11 64 位。本目录为完整便携版，整个文件夹拷走即可用，无需安装。
    程序已内置 fractch 编译器（node.exe + fractch/ 目录），
    不依赖电脑上是否装了 Node 或 fractch。

三、快速开始
    1. 双击 ScratchGenerator.exe 打开程序。
    2. 在「设置」里：
       - 选择厂商（如 DeepSeek）与档位（快速 / 标准 / 强力）。
       - 填入该厂商的 API Key。
       - （可选）指定 TurboWarp.exe 路径，用于生成后自动打开。
       点「保存配置」。
    3. 在主界面输入框里描述你要做的项目，点「发送」（或按 Enter）。
    4. 生成完成后，程序会把 .sb3 输出到本目录，并尝试用 TurboWarp 打开。

四、API Key 说明
    Key 只保存在本程序目录下的 config.json 里（明文，注意保管，不要外发）。
    程序不会联网上传 Key，仅用于调用你选择的 AI 厂商接口。
    也可用环境变量做兜底：DEEPSEEK_API_KEY。应用内填写的 Key 优先。

五、关于档位（重要）
    你只需要选「档位」，不用管具体模型名：
      - 快速（便宜）：日常够用，成本最低。
      - 标准（均衡）：效果与成本的折中。
      - 强力（贵）  ：效果最好，费用较高，会有提醒。
    具体用哪个模型由程序在注册表里维护；主模型不可用时会自动回退到备用模型。

六、用 TurboWarp 打开生成的 .sb3
    - 推荐【便携版 TurboWarp】：下载解压后，在设置里选其中的 TurboWarp.exe，
      生成后即可自动打开对应文件。
    - 微软商店版 TurboWarp：位于受保护的 WindowsApps 目录，程序会改用系统的
      应用激活接口把 .sb3 直接交给 TurboWarp，生成后同样能自动打开，无需手动选文件。
    - 未配置 TurboWarp 时，程序会用系统默认关联程序打开 .sb3。

七、打开 / 修改已有项目、替换素材（拖拽）
    底部输入框是主要入口，把文件或图片直接拖进来即可（附件区和输入框都能放）：
    - 拖入 .sb3 文件：解包并打开该项目；若同时写了文字，会作为第一条修改意见。
    - 已有工程时拖入图片：弹出「替换素材」面板，图片已作为候选，点一下即可指到某一行；
      在输入框写「把背景换成这张图」「把 Guide 的造型换掉」之类的描述，程序会按
      素材名 / 角色名自动匹配到对应行（匹配不到再手动选）。
    - 没有工程时拖入图片：图片作为素材参与新项目生成（需同时写文字描述）。
    - 直接写文字提交：生成新项目（同名工程会被覆盖）；生成完成后继续写文字 = 增量修改。
    输入框支持多行：Enter 发送，Shift+Enter 换行。图片会自动缩放并转成 PNG，无需自己处理尺寸。
    说明：图片既能当素材，也会在所选模型支持「读图」时作为参考图给 AI 看（帮助判断用途与风格）；
    不支持读图的模型会自动跳过这一步，不影响正常使用。

八、目录内容
    ScratchGenerator.exe   主程序
    node.exe               内置 Node 运行时（勿删）
    fractch\               fractch 编译器及其依赖（勿删）
    _internal\             程序运行依赖（勿删）
    vm-runner\             运行时验证组件（含 scratch-vm 依赖，勿删）
    assets_lib\            官方素材库清单与本地缓存（离线可用，勿删）
    config.json            你的配置与 API Key（首次保存后生成）
    使用说明.txt           本文件

九、常见问题
    - 提示 API 报错：检查 Key 是否正确、余额是否充足、所选厂商接口是否可用。
    - 提示找不到 fractch：多为误删了 node.exe 或 fractch/ 目录，请从完整包重新拷贝。
    - 自动打开失败：确认设置的 TurboWarp 路径指向主程序本身（不是安装包）；
      也可先不配置，让程序用系统默认关联程序打开 .sb3。
